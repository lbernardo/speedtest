## Speedtest (Cloudflare Endpoints)

A simple and efficient command-line interface (CLI) tool to measure your internet connection speed using **Cloudflare's** global infrastructure as test endpoints.

---

## 🚀 About the Project

Unlike other speed test utilities that use various third-party servers, this tool focuses exclusively on Cloudflare endpoints. This ensures low-latency testing and high availability by leveraging one of the world's largest edge networks.

**Key Features:**
*   **Latency (Ping):** Measures the response time between your machine and the nearest Cloudflare server.
*   **Download Speed:** Tests the data receiving rate.
*   **Upload Speed:** Tests the data sending rate.
